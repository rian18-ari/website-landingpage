# website-landingpage

Website Landing Page & Web Profile **SMS (Sekolah Mengelola Sekolah)**.

## Fitur Utama
- **Profil Institusi**: Informasi lengkap seputar visi, misi, sejarah, dan nilai-nilai sekolah.
- **Program Pendidikan**: Informasi jenjang pendidikan dari KB-TK, SD, SMP, hingga SMA.
- **PPDB Online**: Formulir interaktif pendaftaran peserta didik baru dengan integrasi WhatsApp.
- **Fasilitas & Galeri**: Dokumentasi fasilitas kampus modern dan arsip kegiatan siswa.
- **Kontak & Lokasi**: Peta lokasi kampus, formulir permohonan kunjungan/tur sekolah, dan FAQ.

## Menjalankan di Lokal

1. **Instal dependensi**:
   ```bash
   npm install --legacy-peer-deps
   ```

2. **Jalankan development server**:
   ```bash
   npm run dev
   ```
   Akses di browser pada: `http://localhost:3000`

3. **Build untuk produksi**:
   ```bash
   npm run build
   ```
